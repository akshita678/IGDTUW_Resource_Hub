# 📚 IGDTUW IT Resource Hub

A centralized, user-friendly web dashboard built specifically for first-year Information Technology students at IGDTUW. This project consolidates essential academic resources into a single, organized platform to help batchmates save time and stay productive.

## ✨ Features
* **🔗 Important Portals:** Quick access links to the official IGDTUW website, Student ERP portal, and examination notice boards using clean anchor tags.
* **📚 Study Materials:** An organized reference list linking directly to the official first-year syllabus, subject notes, and question banks.
* **📅 Class Schedule:** A structured HTML timetable mapping out weekly lectures for quick daily reference.

## 🛠️ Tech Stack
* **HTML5** – Used for core document architecture, lists, tables, semantic text tags, and semantic hyperlinks.

## 🚀 How to Run Locally
1. Download or clone this repository to your local system.
2. Double-click the `index.html` file to open and view the dashboard instantly in any modern web browser.
